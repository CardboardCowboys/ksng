# spectrasonic

[![Thumbnail of the YouTube upload of Spectra Sonic Sound by Nation of Ulysses](http://img.youtube.com/vi/yqTOGT07MwY/0.jpg)](http://www.youtube.com/watch?v=yqTOGT07MwY "Spectra Sonic Sound")

I am so god damn tired of writing audio processing code. This library is meant to abstract the process of reading from audio sources, applying processing, and obtaining outputs.

This is not meant to be a be-all end-all audio processing library. It's meant to abstract away the process of "I need this many frames of audio at this sample rate from this file and I don't care how I get it."
